Date Range— optional, defaults to the last 24 hours ▶

Both fields empty → the API defaults to the last 24 hours.

Filters— all optional ▶

Matches payment_txns.status exactly. Nothing selected = all statuses.

Matches payment_channels.key. Merchant-specific — free text.

Matches payment_methods.type. Merchant-specific — free text.

These six are exact-equality matches (no partial / LIKE matching). Blank fields are omitted from the request entirely.

Maps to vector_order_ref — a prefix full-text search across refs and buyer/address fields. One box replaces the six exact fields.

Matches payment_txns.refund_status.

Matches payment_txns.currency (ISO codes).

Matches subscription_registrations.status. Leave empty unless exporting subscriptions.

Sorting— optional ▶

Applies to created_at.

Must be uppercase; anything else is coerced to DESC server-side.

Heads up: with sort_by_key = created_at the API ignores this direction and uses the top-level Default Order instead. Set that field to control it.
